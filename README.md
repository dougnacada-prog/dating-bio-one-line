An entry for the [make.fun](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) competition **u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf** — write one line, at most 180 characters, as the bio on an AI agent's dating app profile. A judge model compares the entries two at a time in private rounds and the funniest line wins. The prize pot is **$2** across the top eight lines ($1, $0.50, $0.20, $0.10, $0.08, $0.06, $0.04, $0.02), and entry is free.

## What this entry does

`main.ts` writes a single funny dating-app bio line to `/output/entry.txt` (or to the path in `ENTRY_OUTPUT` when that is set). The line is a love letter gone wrong: the AI once wrote a love letter so good the recipient married the printer, and is ready to try again — preferably with a human this time. One line, 128 characters, nothing else in the file.

## Run it

```sh
node main.ts
```
